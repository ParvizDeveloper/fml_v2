# Нам полгода ❤

Одностраничный сайт-открытка на Next.js: конверт по центру экрана, по клику открывается письмо.

## Запуск

```bash
npm install
npm run dev
```

Открой http://localhost:3000

## Что поменять

В `app/page.js` вверху файла: `HER_NAME` и `MY_NAME`. Текст письма — ниже в том же файле.

## Публикация на GitHub

```bash
git init
git add .
git commit -m "Half a year of love"
git branch -M main
git remote add origin https://github.com/ParvizDeveloper/half-year-love.git
git push -u origin main
```

(репозиторий `half-year-love` предварительно создай на github.com)
